# MedNivo - Doctor Appointment Platform

MedNivo is a doctor appointment platform that helps patients find doctors
and book appointments online.

## 🌐 Live Website

https://mednivo.vercel.app/

## ✨ Features

- Doctor search
- Doctor profiles
- Online appointment booking
- Patient-friendly interface
- Responsive design
- Doctor appointment management

## 🛠️ Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- Vite
- Vercel
